Konfigurasi pembayaran

Gunakan Sandbox untuk pengujian terkontrol: pengunjung tidak dapat membayar melalui provider, tidak ada QR sungguhan, dan admin dapat menandai transaksi tes sebagai sukses. Perubahan mode hanya berlaku untuk transaksi baru. API key live tetap disimpan di Environment Variables Vercel dan tidak ditampilkan di dashboard.

Jika tidak memilih foto baru, banner yang sudah ada tetap digunakan.

Pendaftaran online

Bisa menggunakan link undangan WhatsApp, Telegram, atau Discord.

Form peserta berisi nama, jurusan/prodi, semester, dan nomor WhatsApp aktif (+62). Pembayaran berbayar diproses melalui QRIS Zapay.

Pendaftaran hanya tampil jika kegiatan dipublikasikan, tanggal belum lewat, dan opsi ini diaktifkan.
